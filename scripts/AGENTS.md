# Scripts Agent 约定

本文件适用于 `scripts/**`，并继承仓库根 `AGENTS.md`。

## 实现规则

- 脚本用于可重复的仓库构建或发布准备，不承载产品领域规则。
- 路径以仓库根目录或脚本自身位置稳定解析，不依赖调用者碰巧位于某个工作目录。
- 默认非交互、失败即非零退出，并给出可行动的错误信息；不要静默吞掉部分失败。
- 只写入脚本声明的构建输出目录，不覆盖源码、用户文件或未提交改动。
- 不打印环境密钥、连接串、Cookie 或完整敏感 Prompt；不要把真实凭据写入生成物。
- 新增依赖优先复用根 workspace 已有工具；确需依赖时加入正确 workspace 并提交 lockfile。

## 验证

- 对 Node 脚本先做语法/静态检查，再在可控输入上实际运行。
- 修改 `prepare-sites-build.mjs` 等发布路径时运行 `pnpm build`，并检查预期输出而不手改生成目录。
- 完成后运行 `git diff --check`。
