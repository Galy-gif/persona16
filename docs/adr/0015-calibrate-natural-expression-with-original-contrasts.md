# 用原创对照校准中文自然表达，不混合外部语料生成角色话术

persona16 需要让人物的表达习惯自然可辨认，但现成中文对话库没有同时满足真实口语、人物与关系信息、可商用和低采集伪影。产品决定把外部语料限定为统计、对话动作覆盖和失败模式的证据来源，不复制或混合其台词；自己的校准资产使用同一情境下的原创对照回复，按连续表达倾向记录差异，并经真人评审后才成为金标准。

运行时始终先履行本轮对话动作，再按情境从完整表达倾向中抽取最多两项行为证据；简单问候和表达修复可以不显人格。人物辨识在多轮窗口里看行为分布与选择逻辑，不要求单句自报性格、命中口癖或像招牌台词。这牺牲了直接拿大语料做风格模仿的速度，但避免许可风险、影视台词腔、采集任务伪影和“越可辨认越像演人设”的结构性问题。
