# 编译三层关系型 Prompt 与公开碎碎念

- Status: Accepted; production activation pending evaluation
- Date: 2026-08-07

## 背景

旧版人物 Prompt 主要依赖完整人格卡、潜在倾向和单轮语义控制。它已经有安全、关系分支、确认记忆和最终交付门，但缺少统一的关系理论职责边界、带来源覆盖信息的当轮投影，以及用户可见且可关闭的短反应通道。继续给每个人物叠加更多规则会造成系统规则、人物核心和当轮状态互相覆盖。

## 决策

1. 把生产输入编译为 Shared System、Character Prompt 和 Dynamic Context Packet 三层；现有安全层、全局合约核心、关系事件、确认记忆与 `SemanticTurnActPlan` 继续是真相和硬门。
2. 首批四位人物使用同一十维原创 CPAI-inspired 关系镜头和 IPC 情境迁移结构。前者只发现可能相关的关系线索，后者只决定本轮人际动作；两者都不评估用户。
3. IPC 数字不进入模型 Prompt，只渲染定性动作。MBTI 字段只保留为旧数据兼容键。
4. Dynamic Context 明确保存生成时间、轮次/消息覆盖、来源消息、最近原始对话、关系状态、边界、未解决张力、最多三条关系证据、不确定信息和本轮用户原话。未知元数据保持 `unknown`。
5. 新版模型返回 `mutter + reply` JSON。碎碎念是公开表达而非思维链；独立流式、持久化、回放、可关闭，并通过与正文相同的高层安全和叙事诚信规则。
6. `web-mvp-v9` 作为 A 保留。B 关闭人物十维关系镜头，只保留新共同系统、核心与 IPC；C 启用完整三模板。生产只有显式设置 `PERSONA16_PROMPT_VARIANT=relational` 才切换，其他值回退 A。
7. 发布必须经过三批 20 场景盲测。代码层放行门不可跳过安全、结束、修复、边界和历史 100% 要求，且强制比较人物辨识、合理变化、价值因果、中文关系理解、自然度和副作用。

## 后果

- 人物稳定性来自价值和跨场景迁移规律，不来自固定 IPC 峰值或口癖。
- 当轮 Prompt 可以追溯使用了哪些消息和关系证据，旧数据缺口不会被模型补写。
- 客户端和旧 Turn 事件保持兼容；旧消息没有 `mutter`、`turnId` 或时间时正常读取。
- 新版多一次结构化解析，漏协议时可能增加一次重试；trace 记录 Prompt 版本、碎碎念开关/数量、首个可见内容延迟和模型用量。
- 2026-08-07 的 live 评测因所有已配置通道不可用而未开始：AIHubMix 与 DeepSeek 返回余额不足，Anthropic 未配置认证。生产因此保持 A，不能把静态测试记成发布通过。
