# 编译正向关系动作，并用反事实场景校准房间

## Context

协议 0.6 已能把边界和未解决张力编译为禁止/必须动作，但 R1 偏好与共同成功仍主要作为自然语言背景进入 Prompt，无法证明它们真的改变了当轮行为。边界修复又与普通倾听、语气修复共用表达路径，容易把“归还选择权”实现成新的修复菜单。

动态房间此前只有维护责任缺口一个主场景。它不能反事实验证全员沉默、用户点名、信息不足时只问一个问题，以及四人明确分工时全部发言。

## Decision

### 独立边界修复

- 用户指出人物已经越过回应边界时，编译独立 `boundary_repair`。
- 人物必须承认具体越界并主动停止介入；禁止建议、问题、菜单、动机解释和重开话题。
- 选择权通过人物先停归还，不要求用户当场选择如何修复。
- active boundary 或 unresolved tension 始终覆盖正向关系动作。此项替代 ADR-0016 中“用户当轮明确请求建议即可解除未修复 R2 收紧”的例外；解除必须来自对应修复接受、边界修订、遗忘或关闭。

### 每轮一个可验证正向动作

- `RelationshipContextEvidence` 从既有事件日志投影可选事件类型，不新增持久化字段。
- support、conflict、ordinary 可从已确认偏好编译 `honor_stated_preference`；decision 可从共同成功编译 `reuse_verified_method`。
- 首版只编译有窄、可机械检查 observable cue 的关系经验：诚实但不过度笃定的判断、第一句先给条件化结论、简短回复、最多一个问题、不主动建议、例子先行，以及当前可执行且可停止/撤回的小实验。无法可靠验证的关系记录只保留为上下文，不伪装成已落实动作。
- 偏好内容显式声明“讨论/聊到 X 时”等适用范围时，编译器必须用当前用户消息匹配 X；未命中时不生成正向动作。未声明范围的回应方式偏好按当前 focus 适用。
- 最终文本以同一 `SemanticTurnActPlan` 检查 observable cue。生成指令、交付验证和逐事件蕴含共同证明行为差异；不能只挂事件 ID。

### 双层交付统计

- 评测同时保存原始模型结果与最终产品交付结果。
- 重试耗尽后可使用与生产一致、且通过同一语义计划验证的降级文本作为最终交付；Judge 可以评价最终交付，但原始模型结果保持失败。
- 每批边界修复最终交付必须 4/4，原始模型至少 3/4。任一门失败，批次总门失败。
- room-only artifact 复用必须匹配当前提交 SHA；修复双层门从已验证的逐条回复重新计算，不信任 artifact 中的汇总字段。
- 真实复测启动前必须确认引擎、评测和协议源文件相对 HEAD 无未提交改动；范围外 UI 工作树不影响评测冻结。
- 这一双层口径细化 ADR-0009/0016 的“失败草稿不能进入 Judge”：原始失败草稿仍不得评分或伪装成通过；只有独立标记的安全降级交付可以进入产品交付评价。

### 反事实房间

- 房间协议改为 case table。每个 case 独立声明允许停止原因、人数、首位、必要人物、消息依赖下限、是否需要共享正典关系，以及现实责任声明边界。
- 参与意向增加 `ask_user`；执行一个澄清问题后立即以 `needs_user_input` 停止。
- 固定覆盖维护责任缺口、全员 pass、点名首位、信息不足、四人明确分工五类场景。
- case 的确定性约束必须在化学反应 Judge 前验证；失败时不运行 Judge。
- 此项替代 ADR-0011 的单场景“固定允许 1–4 人发言”。0、1 或 4 人都可以是正确结果，但只能由各 case 的明确约束决定，不形成全局发言配额或顺序。

## Consequences

- 关系可感知性来自当轮动作变化，而不是关系状态播报。
- 关系编译保持窄：新增 observable cue 必须来自真实失败样本，并同时增加正反单测。
- 房间评测成本上升，但能区分自然沉默、等待用户和必要全员发言。
- 协议升级为 0.7，Prompt 装配升级为 `pilot-runtime-prompt-v0.7`，房间参与升级为 `pilot-room-participation-v0.2`；旧 artifact 不得复用为当前完整结果。
- 当前仍是组件校准，不代表真实用户满意度、留存或人物定位已经验证。
