# 人物倾向默认休眠，只在相关且获得许可时显影

## Context

生产 Prompt 曾把四位正典人物的第一印象、价值、核心矛盾、不可漂移项和场景注意力长期放在生成上下文中。即使普通互动镜头要求“不要强行分析”，模型仍会先看到强烈的主题性人物信息，并容易把它们变成每轮认知反射：

- 林衡从轻松分享中寻找风险、后果和无人负责的变量；
- 夏栩从明确表达中寻找仍未关闭的可能；
- 周禾把普通话题转成照顾、维护和承受；
- 许野把尚未请求行动的内容转成现实试验。

这会让人物在第一句话里就暴露完整功能，也会把“长期可辨认”错误实现成“句句证明人设”。真实人物的稳定性更接近多轮行为分布：主题性倾向可以长期存在，但大多数轮次不需要进入注意、表达或可见回复。

## Decision

### 常驻人物存在

生产稳定前缀只保留：

- 人物姓名；
- 一段不绑定具体话题的轻量社交存在；
- 人物不必每轮证明自己的明确许可；
- 叙事诚信约定。

第一印象、价值冲突、注意列表、塑造性事件和完整人物卡继续作为正典与 Judge 真相源，不再默认进入每轮生产前缀。

### 潜在倾向目录

四位人物各自拥有三项版本化潜在倾向。每项分别声明：

- `id`；
- 仅供 Director 判断相关性的 `activateWhen`；
- 通过许可门后才进入生成上下文的 `guidance`。

潜在倾向默认全部休眠。Director 每轮为每位人物只能选择零项或一项，并同时给出当前话题的新增角度。未知 id 或属于其他人物的 id 在确定性装配中被丢弃。

### 生成前许可门

Director 的选择只是候选，不能直接让倾向进入生成。人物生成前还要满足：

- 当前基础对话动作是普通回应，而不是问候、表达修复、边界修复或直接冲突；
- 当前互动不是倾听、修复或结束；
- 用户明确邀请分析、建议或共同决定；或者关系已有多轮/可信证据且当前确实是决策或分歧；多人房则由新增价值与房间发言许可共同约束。

未通过许可门时，人物倾向和 Director 的人物化 angle 都不进入生成。新关系的普通首轮不额外抽取表达倾向；多轮关系可以逐渐显影，但仍不强制激活主题性倾向。

### 对话优先于人格

全局合约改为：

1. 先由当前对话决定回应什么；
2. 再由已激活的至多一项人物倾向决定是否带入不同角度；
3. 没有新增价值时保持普通回应或多人房沉默。

场景仍用于动作与安全裁决，但生产人物投影不再把七类场景各自绑定到人物注意列表。

### 版本与评测

- 生产 Prompt 版本升级为 `web-mvp-v9`。
- 试点 Prompt 装配升级为 `pilot-runtime-prompt-v0.9`。
- 协议 0.8 的交付硬门、质量观察和模型健康定义保持不变。
- 旧 Prompt 产物不能作为 v0.9 Prompt 的当前人物质量证据；正式三批付费模型复测与隐藏来源人工盲审仍需单独授权。

## Consequences

- 普通、轻松和首次互动可以完全不展示主题性人物功能。
- 人物可辨认性从单句水印转向多轮选择逻辑和行为分布。
- Director 可以使用完整倾向目录判断相关性，但生成 Module 的 Interface 只接受一个已选候选，并在内部执行许可、归属和数量限制。
- 正典人物完整档案仍保留，因此本决定改变的是生产投影方式，不重写四人的正典经历与核心矛盾。
- 单元测试只能证明装配、休眠和许可规则按设计工作；它不能替代真实模型自然度、人物辨认或长期关系验证。
