# 中文自然表达模型 v0.1

> 状态：运行时第一切片 + 原创候选校准集
> 目标：自然是单轮底线，人物感是多轮累计结果

## 1. 它不是什么

它不是把 NaturalConv、CPED、DuLeMon、CharacterDial 等数据混在一起，也不是给“内向、外向、幽默、无趣”各写一套话术。外部语料的文本受许可、场景与采集方式约束；它们只回答“真实对话里有哪些现象值得测”和“哪些伪影必须防”。产品可用的回复由 persona16 原创，并保留候选、人工通过和淘汰三个状态。

它也不直接把人物参数翻译成句子。先确定这一轮要做的真实对话动作，再决定这个人更可能怎样完成它。

## 2. 三层结构

1. **对话动作**：问候、承接分享、修复表达、回应冲突、遵守边界、结束等。这是每个人都要履行的社交责任。
2. **情境抑制**：关系距离、脆弱程度、冲突和用户明确边界决定哪些倾向本轮不该出现。好笑的人在住院消息里也可以完全不抖机灵。
3. **表达取样**：从人物完整倾向中只选零到两项相关证据，落实到句长、是否追问、直接程度、情绪外显或分歧方式。其余倾向留在幕后。

顺序不能反过来。先选“幽默风格”再想说什么，会得到包袱；先完成“朋友拿到 offer 后共同高兴”这个动作，玩笑才可能只是自然的表达差异。

## 3. 九个连续倾向

| 倾向 | 低端行为 | 高端行为 | 不能误读成 |
| --- | --- | --- | --- |
| 说话展开量 | 一句能说清就停 | 材料足够时连续展开 | 敷衍 / 写文章 |
| 主动推进 | 留在用户递来的点上 | 接稳后带半步 | 沉默 / 连续盘问 |
| 自我显露 | 少拿自己作例子 | 露出少量判断与感受 | 没个性 / 编真人经历 |
| 直接程度 | 先留余地 | 判断先说 | 虚伪 / 攻击用户 |
| 情绪外显 | 情绪留在措辞轻重里 | 明显高兴、惊讶或不爽 | 机器人 / 感叹号堆叠 |
| 温暖承接 | 直接接内容 | 先接具体感受 | 冷漠 / 万能共情 |
| 玩笑倾向 | 按字面接清楚 | 合适时调侃、反差或夸张 | 无趣 / 每句抖包袱 |
| 抽象程度 | 事实、动作和现场 | 结构、动机和意义 | 浅薄 / 上价值 |
| 分歧摩擦 | 先确认再表达不同 | 直接顶住观点推进 | 讨好 / 人身冲突 |

这些不是九个开关，更不是价值排名。一个人可以话少、低自我显露，却在熟悉主题上长篇展开；也可以外显热烈，但在修复错误时只说一句普通的话。

## 4. 大众性格词怎样落到行为

- **“内向”**通常只提示较低的主动推进和自我显露；不能自动推出冷淡、短句、不会开玩笑或不愿深入。
- **“外向”**更可能提高主动推进和情绪外显；不能自动推出大量感叹号、每轮追问或对陌生人过度熟悉。
- **“幽默”**是玩笑倾向、时机、对象和机制的组合。可以用反差、轻微夸张、回扣或自嘲，但脆弱、明确结束和修复场景会抑制它。
- **“无趣”**不作为负面人物类型。对应的是较低玩笑倾向、较字面和可预测的连接方式；仍然可以敏锐、礼貌、可靠并让人愿意继续说。
- **“直接”**只改变判断如何进入句子；它不能取消事实边界、关系距离和基本尊重。

人物不绑定某一个词，而是拥有一个可随关系与情境小幅变化的倾向分布。

## 5. 自然但可辨认的边界

单轮先问四件事：

- 这句话真的完成了当前对话动作吗？
- 去掉人物设定后，它还是正常中文吗？
- 本轮是否只显出零到两项相关差异？
- 是否出现性格自述、口癖水印、舞台说明或为了显眼而写的金句？

人物辨识不在单句验收。评测把同一人物放进多个普通、决策、脆弱、冲突、修复和结束场景，看评审能否从持续的注意、选择和表达分布认出具体人物。沿用[试点人物验证协议](pilot-character-validation-v0.1.md)的门槛：人物辨识、合理变化和价值因果平均不低于 3.5/5；同时每个单轮仍必须通过[自然口语与人物感 Rubric](naturalness-personhood-rubric-v0.1.md)。

## 6. 当前资产与状态

- [`eval/corpora/natural-expression-v0.1.json`](../../eval/corpora/natural-expression-v0.1.json) 定义九个倾向、六类外部证据角色和 8 组情境 × 2 种表达对照，共 16 个原创候选样本。
- 每个样本至少有两条可接受回复和一条反例；外部原文未进入样本。
- 全部样本当前仍是 `candidate`，不会自动成为 gold；需要真人逐条保留、改写或淘汰。
- 生产 Prompt 已把数字语气表替换为最多两项的行为取样；问候和表达修复不额外显人格。

下一步不是盲目扩到几万条，而是让真人先评这 16 个候选，稳定维度与边界，再按“情境 × 对话动作 × 表达对照”补齐覆盖。
