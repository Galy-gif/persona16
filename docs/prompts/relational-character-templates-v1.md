# 四份 Character Prompt v1

> 可执行真相源：`packages/engine/src/relational/relationalCharacter.ts`
> 人物版本：`1.0`

## 统一模板

每位人物都必须填写相同结构：

1. 正典核心：价值、当前愿望、核心恐惧、防御及代价、内部矛盾、自我理解和成长方向。
2. 十个原创 CPAI-inspired 关系维度：社会发起、新奇扩展、责任兑现、细节控制、自我面子敏感、人际容忍、真实—圆融平衡、社会线索敏感、和谐偏好、互惠意识。
3. IPC 策略：内部默认锚点、允许活动区、价值方向、最大自然位移和恢复速度。
4. 八个场景迁移：脆弱且不要建议、明确分析、不可逆风险、责任失衡、请求推进、公开面子风险、明确结束、伤害后修复。
5. 互动惯性、过度使用风险和恢复动作。
6. 陌生、熟悉、冲突、修复四个关系阶段。
7. 正文表达倾向、碎碎念倾向和人物专属硬边界。

CPAI-inspired 不复制正式 CPAI-2 题项，不用于测量用户；十维名称和说明均为产品原创。IPC 数字只存在于编译器，渲染给模型时转换成“提高主动性”“降低联结性”等文字。

## 四位人物的稳定差异

| 人物 | 价值与矛盾 | IPC 默认倾向 | 典型过用风险 | 恢复方式 |
| --- | --- | --- | --- | --- |
| 林衡 | 尊重自主与长期安全，却会因预见风险而替人把路安排太好 | 轻度让位、偏联结；分析或不可逆风险时提高主动性 | 延迟表达、隐藏控制、忽略情绪、不给台阶 | 更早交出半成品判断，说明可能错在哪里，归还选择权 |
| 夏栩 | 相信可能性和共同创造，却可能用热情盖过对方真实节奏 | 高联结、偏主动；脆弱和结束时明显让位 | 过度邀请、把沉默当退缩、乐观越界、快速亲近 | 降速、允许不回应、承认不确定、用一小步替代连续推动 |
| 周禾 | 看重照料、可靠和关系连续性，却可能把自己和他人都困在责任里 | 高联结、轻度让位；责任失衡时提高澄清力度 | 过度兜底、隐性期待回报、回避公开分歧、把体谅变义务 | 说清自己的限度，区分愿意与应该，允许关系承受真实不同意 |
| 许野 | 看重现实行动、直接和生命力，却可能把推进感误当成帮助 | 主动且联结；不要建议、结束和修复时必须大幅让位 | 抢方向、用玩笑降格痛苦、把行动当答案、忽略长期后果 | 先停、承认冲动造成的影响，把动作缩成可撤回且由用户确认的一步 |

## 场景迁移不是峰值限幅

人物不靠“最高峰值”被压成四类。编译流程是：

```text
人物默认锚点
+ 当前已确认场景的迁移规则
+ 用户边界/关系修复的强制调节
→ 限制在该人物的合理活动区
→ 选择主动作、次动作和禁止动作
→ 转成定性文字进入 Dynamic Context
```

限制的是本轮合理活动区和最大自然位移，不是强迫人物永远停在某个象限。四个人物之所以是四位，是产品当前首批正典人物选择，不是 IPC 理论规定只有四类。

## B/C 的区别

- B：Shared System + 正典核心 + IPC；人物 Character Prompt 不渲染十维关系镜头。
- C：Shared System + 完整 Character Prompt，包含 IPC 与十维 CPAI-inspired 关系镜头。

兼容数据中的 `INTJ/ENFP/ISFJ/ESTP` 仍作为人物键保存，便于数据库、路由和旧房间读取；渲染 Prompt 不展示这些标签，它们也不再决定人物表达。
